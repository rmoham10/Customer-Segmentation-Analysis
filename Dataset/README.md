
## 📊 Dataset Overview

This project uses a retail customer dataset sourced from Kaggle, containing information about customer demographics, purchasing behavior, and promotional activity.

### 🔹 Key Details:
- **Total Records:** 3,900 customers
- **Total Features:** 19
- **Data Type:** Structured (CSV format)

### 🔹 Feature Categories:
- **Demographics:** Age, Gender, Location
- **Shopping Behavior:** Category, Size, Purchase Amount (USD), Previous Purchases
- **Promotional Usage:** Promo Code Used, Discount Applied, Is Promo Buyer (engineered)
- **Other Attributes:** Subscription Status, Review Rating, Payment Method, Shipping Type

The dataset enables end-to-end customer segmentation based on real-world shopping behavior and supports personalized marketing strategies.
